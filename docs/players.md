# Worlds and portals

Atlas manages travel and the rules that apply in each world. You do not need to open an Atlas menu or run an Atlas command to use a portal: walk into it. Atlas messages are shown in English.

## Travelling

A portal can take you to a world's spawn, a saved location, or the matching world on the other current server region. When a cross-region route is configured, Atlas sends you through the network and completes the trip on arrival. If a destination is closed, you lack access or the trip cannot be confirmed, follow the message and contact staff. Atlas preserves an uncertain trip as uncertain; do not repeatedly use the portal when the result is unclear.

The configured portal cooldown applies after a route attempt. Its exact value can differ by portal. Restricted portals also require permission granted by staff.

Atlas can teleport you to a loaded world using staff tools. It does not load a destination world on demand. A newly created or enabled world becomes available after a server start; a clone or reset can take a preparation start and a later activation start.

## World rules

Staff can set different rules in each world, including mob spawns, PvP, block breaking/placing, damage, hunger, item drops and pickups, time, weather, sleep and trading. Some worlds set a forced game mode. Leaving that world does not guarantee that your previous game mode is restored automatically.

If an action is refused, Atlas will show a message when that action has a player-facing message. A world may intentionally prevent the action. Ask staff if a rule or destination seems unexpected.

## Item, menu and block availability

Atlas has one staff-issued tool: the **Atlas Selector**. It is a single unbreakable wooden axe used by staff to mark two block corners when creating portals or keep-loaded regions. Players do not obtain it through a recipe, reward or public command. The item uses the Closet-provided pack for its name and small action glyph.

Atlas has no custom blocks, recipes, player rewards or inventory GUI. Portals may use an ordinary placeable block as their visible fill; this does not add a custom block or item.

## Commands

Players use portals directly. There is no player-facing Atlas menu. If staff sends you to collect a selector from overflow, follow the message and use `/overflow` when you have inventory space. All other `/atlas` management commands are for authorized staff.

## Frequently asked questions

**A portal did not move me.** Check the message. The portal may be on cooldown, restricted, disabled by the world rules, or pointed at a world that is not loaded. Ask staff if it keeps happening.

**I cannot build, fight, trade or pick up an item here.** That action may be disabled in this world. Atlas applies its per-world rules; ask staff which worlds allow the action.

**A world is not available yet.** World declaration changes take effect at a server start. Clone/reset can require a preparation start and a later activation start.

**I changed worlds and my game mode did not return.** A destination world may have a forced mode. Atlas does not promise to restore a prior mode when you leave; ask staff if you need help.

**I need the Atlas Selector.** Players cannot issue it themselves. Staff can request it for an online local player. If it is awaiting overflow delivery, use `/overflow` when there is space.
